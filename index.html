每日营养 · 按日类型循环

周均≈2000 kcal(约350赤字,~0.3kg脂肪/周)。碳水在训练日堆高、休息日压低——能量给到长肌肉的时候。

为什么这样吃

  • 蛋白 165g ≈ 2.2g/kg,每天不变——减脂保肌的绝对命脉
  • 脂肪 60g = 0.8g/kg,激素下限;省下的热量全给碳水
  • 训练日碳水 237g / 休息日 163g,把糖原和能量分配给训练
  • 84天预期:74.45kg/~17% → 约 72kg / 12–13%,瘦体重持平或微增,腹围86→~80,腹线显形
为什么是慢刀不是猛冲? 你21岁、17%、有训练基础——这是身体重组的黄金条件:小赤字+高蛋白+渐进负重,可以一边掉脂一边长肌。赤字拉太狠只会掉肌肉、掉线条、易反弹。慢=薄肌。

🍚 放纵日 / 补碳日(你自己在「每日」里点)

两个概念别搞混

  • 补碳日 Refeed(2500kcal):升到维持热量、几乎全靠碳水,蛋白不变、脂肪压住。有科学依据:回补肌糖原、拉回瘦素/T3、缓解节食疲劳、下次练更猛。不是随便吃。
  • 自由日 Free(~2800kcal):真正放开,频率低很多,每3–4周最多一次。

科学节点(网页已按此标黄点)

  • 周期内:17%这个体脂,每10–14天一次够了;掉到13%以下再加密到每7天
  • 周内:只放训练日,且是最重/腿日那次,练后那一餐——胰岛素敏感、糖原窗口开着,多的热量更多进肌肉
  • 禁忌:别放休息日(糖原满、更易转脂)、别连着两天
  • 候选节点:第 12 / 24 / 36 / 48 / 60 / 72 / 84 天(进度条上带小黄点)——就近挪到你那几天最重的训练日
操作:进度条上有黄点的日子,如果你当天练了大重量,就在「每日」页把日类型点成「补碳日」,目标自动升到2500/碳水314g。不想补就保持休息/训练日。

训练分化(每周3–4练)

A 推胸 + 肩 + 三头 · 练后 Zone2 走 20min
B 拉背 + 二头 · 练后 Zone2 走 20min
C 腿+核心腿 + 腹斜 · 最重的一天→适合当补碳日
循环A→B→C→A… 每周练3–4次,其余休息日走8000步
渐进超负荷是腹线唯一的来源:每次记重量×次数,下次加1次或加重量。减脂期力量「保住」就是胜利。腹肌靠低体脂显形,不是靠多练卷腹。

有氧与心率

最大心率 ≈ 199 bpm(21岁)

  • Zone 2(119–139):主用,保肌肉易恢复
  • Zone 3(139–159):心肺
  • Zone 4-5(159–199):HIIT,压恢复,每周≤1次
走路是最大红利:久坐一天NEAT很低,每天8000步不掉肌肉不压恢复,比跑步机HIIT更值。别用有氧代替饮食缺口——赤字主要靠吃,有氧是补充。

关键提醒

三个决定成败的点

  • 肚子不显线条=体脂问题,不是肌肉不够:男性通常~12–13%才见腹线,下腹更晚。杠杆是降脂保肌
  • 保肌肉:蛋白每天165g + 力量不断档 + 赤字别拉太狠
  • 久坐是最大浪费:把日常步数提上来,这是你TDEE里最容易拿的一块

肠道与消化

  • 纤维每天:菠菜/绿豆角 + 香蕉 + 奇亚籽
  • 水2升/天;餐后等20–30分钟再躺
